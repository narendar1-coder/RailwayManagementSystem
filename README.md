# RailwayManagementSystem
## Project Description

Railway Management System is a Java-based console application that manages railway operations such as train information, passenger details, and ticket booking.

## Features

- Add passenger details
- View train details
- Ticket booking
- Display booking status
- Simple menu-driven application

## Technologies Used

- Java
- OOP Concepts
- Git
- GitHub

## Software Requirements

- JDK 17+
- VS Code
- Git

## Steps to Run

1. Clone the repository

git clone <repository-url>

2. Open project in VS Code

3. Compile

javac *.java

4. Run

java Main
